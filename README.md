# TokenPulse — descargas

Instaladores de **TokenPulse** para Windows: un monitor de cuota y uso de asistentes de IA (Claude Code, OpenAI, Claude API, DeepSeek, OpenRouter, Ollama).

Descarga la última versión desde [Releases](../../releases/latest) (`TokenPulse_<versión>_x64-setup.exe`). No requiere permisos de administrador.

- Todos los datos se guardan en tu equipo. No hay telemetría.
- La aplicación instalada consulta `latest.json` de este repositorio para avisarte de nuevas versiones. Puedes desactivarlo en Ajustes.
- Cada instalador va acompañado de su firma (`.sig`). La aplicación solo instala actualizaciones firmadas con la clave de TokenPulse.
- Mientras el instalador no tenga firma de código de Windows, SmartScreen puede mostrar un aviso: "Más información" → "Ejecutar de todas formas".

Este repositorio solo contiene versiones publicadas; el código fuente es privado.
